## Cómo usar esta web

1. **Mira el [mapa del examen](/mapa/)**: qué preguntas se repiten año tras año y cuántos puntos valen.
2. **Repasa por unidad** con la barra lateral. Cada página sigue el mismo orden: teoría → avisos «en el examen» → simulador → ejercicio con solución desplegable → quiz.
3. **Resuelve un examen previo cronometrado** antes de abrir las soluciones.
4. **Cierra con las [flashcards](/examen/flashcards/)**. Tu progreso se guarda en este navegador.

:::caution[Sobre las soluciones]
Los exámenes 2024-I y 2024-II traen solucionario oficial. Para 2026-1, 2025-2 y 2021/22 las soluciones son **propias** y están marcadas así. Todo el código C se compiló y ejecutó en WSL (`~/so/verif_parcial`).
:::
