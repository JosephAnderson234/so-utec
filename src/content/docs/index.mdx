## Cómo usar esta web

La barra lateral tiene dos etapas: **Final** (arriba, abierta) y **Parcial · E1** (plegada). El final se apoya en el parcial, así que las páginas del final enlazan a las del parcial cuando hace falta.

1. **Mira el mapa de la etapa que estudias:** [mapa del final](/final/) o [mapa del parcial](/mapa/): qué preguntas se repiten año tras año y cuántos puntos valen.
2. **Repasa por unidad** con la barra lateral. Cada página sigue el mismo orden: teoría → avisos «en el examen» → simulador → ejercicio con solución desplegable → quiz.
3. **Resuelve un examen previo cronometrado** antes de abrir las soluciones. Después, haz los **[3 simulacros del E1 2026-2](/examen/prediccion/)**: preguntas nuevas en el estilo del examen, con pauta de corrección.
4. **Cierra con las [flashcards](/examen/flashcards/)**. Tu progreso se guarda en este navegador.

:::caution[Sobre las soluciones]
Los exámenes 2024-I y 2024-II traen solucionario oficial. Para 2026-1, 2025-2 y 2021/22 las soluciones son **propias** y están marcadas así. Todo el código C se compiló y se probó en ejecuciones de prueba.
:::
