<EnSimple>
Estos ejercicios juntan dos decisiones del SO. El **scheduler** decide **en qué orden** corren los procesos, y como cada unidad de CPU hace un acceso a memoria, ese orden produce la **cadena global de referencias**. Después, el algoritmo de **reemplazo** decide qué página sale cuando los frames están llenos. Cambiar el scheduler cambia la cadena, y con eso cambian los page faults, aunque los procesos sean los mismos.
</EnSimple>

:::caution[Convenciones (escríbelas en tu respuesta)]
- Se cuentan **todos** los fallos, incluidos los de arranque con frames vacíos.
- Un frame vacío se llena **sin expulsar a nadie**, en orden: frame 0, 1, 2.
- **Clock** (lo pide la hoja): los bits de uso empiezan en 0 y el puntero en el **primer frame**. Al cargar una página, su bit pasa a 1 y el puntero avanza al siguiente frame. En un **acierto**, el bit pasa a 1 y el puntero **no se mueve**.
- **OPT:** si dos páginas no se vuelven a usar, saco la del frame de menor número (cualquiera da el mismo número de fallos).
:::

## Ejercicio 1: los cuatro algoritmos con la misma cadena

Cadena `A B C A D B E A C D B E`, con 3 frames inicialmente vacíos.

<Predice pregunta="Antes de simular, ordena de menos a más fallos: FIFO, LRU, OPT y Clock. ¿Crees que LRU le gana a FIFO?">

OPT siempre es el mínimo (**7**), pero **LRU pierde contra FIFO**: 11 contra 10. La cadena repite un ciclo de 5 páginas con solo 3 frames, y LRU siempre expulsa justo la que se va a usar pronto. Clock da 10, igual que FIFO. «LRU aproxima a OPT» vale con localidad, no siempre.

</Predice>

<Solucion titulo="Comparar: Clock (10 fallos)">

El * marca u = 1. «Puntero» es el frame al que apunta **después** de la referencia.

| Ref. | f0 | f1 | f2 | Fallo | Puntero | Qué pasó |
| :-: | --- | --- | --- | :-: | :-: | --- |
| A | A* | | | ✗ | f1 | f0 vacío |
| B | A* | B* | | ✗ | f2 | f1 vacío |
| C | A* | B* | C* | ✗ | f0 | f2 vacío; el puntero da la vuelta |
| A | A* | B* | C* | | f0 | acierto: u ya era 1, el puntero no se mueve |
| D | **D*** | B | C | ✗ | f1 | apaga A, B y C, vuelve a f0 (ahora u = 0) y saca **A** |
| B | D* | B* | C | | f1 | acierto: u de B = 1 |
| E | D* | B | **E*** | ✗ | f0 | apaga B; f2 tiene C con u = 0 → sale **C** |
| A | D | **A*** | E* | ✗ | f2 | apaga D; f1 tiene B con u = 0 → sale **B** |
| C | **C*** | A* | E | ✗ | f1 | apaga E; f0 tiene D con u = 0 → sale **D** |
| D | C* | A | **D*** | ✗ | f0 | apaga A; f2 tiene E con u = 0 → sale **E** |
| B | C | **B*** | D* | ✗ | f2 | apaga C; f1 tiene A con u = 0 → sale **A** |
| E | **E*** | B* | D | ✗ | f1 | apaga D; f0 tiene C con u = 0 → sale **C** |

**10 fallos.** Quedan **E, B, D**: el mismo conjunto que FIFO, pero en otros frames y con otros bits.

</Solucion>
</Practica>

**Resumen del ejercicio 1** (verificado con un script y con el programa en C de abajo):

| Algoritmo | Fallos | Quedan cargadas |
| --- | :-: | --- |
| FIFO | 10 | E, D, B |
| LRU | 11 | D, B, E |
| OPT | **7** | B, E, D |
| Clock | 10 | E, B, D |

Con más frames, FIFO baja 12 → 12 → 10 → 7 → 5 (de 1 a 5 frames) y LRU 12 → 12 → 11 → 9 → 5: en esta cadena no hay anomalía de Belady.

<Solucion titulo="El ejercicio 1 implementado en C (la hoja dice «implemente»)">

```c
#include <stdio.h>
#include <string.h>

#define FRAMES 3

char refs[] = "ABCADBEACDBE";

int find(char *fr, char p) {
    for (int i = 0; i < FRAMES; i++)
        if (fr[i] == p)
            return i;
    return -1;
}

void show(char r, int hit, char *fr, int *bit) {
    printf("%c %s |", r, hit ? "hit " : "FAIL");
    for (int i = 0; i < FRAMES; i++) {
        if (fr[i] == 0)
            printf(" -");
        else if (bit)
            printf(" %c%s", fr[i], bit[i] ? "*" : " ");
        else
            printf(" %c", fr[i]);
    }
    printf("\n");
}

int fifo(void) {
    char fr[FRAMES] = {0};
    int next = 0, faults = 0, n = strlen(refs);
    for (int k = 0; k < n; k++) {
        int hit = find(fr, refs[k]) != -1;
        if (!hit) {
            fr[next] = refs[k];
            next = (next + 1) % FRAMES;
            faults++;
        }
        show(refs[k], hit, fr, NULL);
    }
    return faults;
}

int lru(void) {
    char fr[FRAMES] = {0};
    int last[FRAMES] = {0}, faults = 0, n = strlen(refs);
    for (int k = 0; k < n; k++) {
        int j = find(fr, refs[k]);
        int hit = j != -1;
        if (!hit) {
            j = find(fr, 0);
            if (j == -1) {
                j = 0;
                for (int i = 1; i < FRAMES; i++)
                    if (last[i] < last[j])
                        j = i;
            }
            fr[j] = refs[k];
            faults++;
        }
        last[j] = k;
        show(refs[k], hit, fr, NULL);
    }
    return faults;
}

int opt(void) {
    char fr[FRAMES] = {0};
    int faults = 0, n = strlen(refs);
    for (int k = 0; k < n; k++) {
        int hit = find(fr, refs[k]) != -1;
        if (!hit) {
            int j = find(fr, 0);
            if (j == -1) {
                int far = -1;
                for (int i = 0; i < FRAMES; i++) {
                    int d = n;
                    for (int m = k + 1; m < n; m++)
                        if (refs[m] == fr[i]) {
                            d = m;
                            break;
                        }
                    if (d > far) {
                        far = d;
                        j = i;
                    }
                }
            }
            fr[j] = refs[k];
            faults++;
        }
        show(refs[k], hit, fr, NULL);
    }
    return faults;
}

int clock_alg(void) {
    char fr[FRAMES] = {0};
    int use[FRAMES] = {0}, ptr = 0, faults = 0, n = strlen(refs);
    for (int k = 0; k < n; k++) {
        int j = find(fr, refs[k]);
        int hit = j != -1;
        if (hit) {
            use[j] = 1;
        } else {
            while (fr[ptr] != 0 && use[ptr] == 1) {
                use[ptr] = 0;
                ptr = (ptr + 1) % FRAMES;
            }
            fr[ptr] = refs[k];
            use[ptr] = 1;
            ptr = (ptr + 1) % FRAMES;
            faults++;
        }
        show(refs[k], hit, fr, use);
    }
    return faults;
}

int main(void) {
    printf("== FIFO\n");
    printf("fallos = %d\n\n", fifo());
    printf("== LRU\n");
    printf("fallos = %d\n\n", lru());
    printf("== OPT\n");
    printf("fallos = %d\n\n", opt());
    printf("== CLOCK (* = bit de uso en 1)\n");
    printf("fallos = %d\n", clock_alg());
    return 0;
}
```

Notas de diseño:

- **FIFO** no necesita marcas de tiempo: como los frames se llenan en orden y siempre se reemplaza en el siguiente, basta un índice circular `next`.
- **LRU** guarda en `last[j]` la última referencia de cada frame.
- **Clock** reutiliza el mismo puntero para llenar los frames vacíos.

La ejecución de prueba imprime `fallos = 10`, `11`, `7` y `10`, con las mismas tablas de arriba.

</Solucion>

## Ejercicio 2: Round Robin + FIFO

P1 accede a `A, B, A, C` y P2 a `D, E, D, F`, **una referencia por unidad de CPU**. RR con q = 2, ambos llegan en t = 0 y P1 va primero. Hay 3 frames compartidos y FIFO.

<Practica nivel={2} titulo="Complétalo: primero el Gantt, después la cadena global">

El Gantt es P1 0–2 · P2 2–4 · P1 4–6 · P2 6–8. ¿Cuál es la cadena global? Simúlala con FIFO.

<Solucion titulo="Comparar">

Cadena global: **A B** (P1) · **D E** (P2) · **A C** (P1) · **D F** (P2).

| Ref. | A | B | D | E | A | C | D | F |
| --- | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| Proceso | P1 | P1 | P2 | P2 | P1 | P1 | P2 | P2 |
| f0 | A | A | A | **E** | E | E | **D** | D |
| f1 | | B | B | B | **A** | A | A | **F** |
| f2 | | | D | D | D | **C** | C | C |
| Fallo | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ |
| Sale | | | | A | B | D | E | A |

**8 fallos de 8 referencias: P1 = 4, P2 = 4.** Quedan **D, F, C**. Cada proceso, solo, tendría 3 fallos y 1 acierto (la página que repite). Intercalados, con 3 frames para 6 páginas distintas, cada uno **expulsa** la página que el otro está por reutilizar: A sale justo antes de que P1 la vuelva a pedir, y D justo antes de que P2 la pida. Es un **thrashing** en miniatura.

</Solucion>
</Practica>

<Practica nivel={4} titulo="Variante: ¿y con q = 4?">

<Solucion titulo="Comparar">

Con q = 4 cada proceso corre entero: la cadena es `A B A C D E D F`. FIFO: A ✗, B ✗, A ✓, C ✗, D ✗ (sale A), E ✗ (sale B), D ✓, F ✗ (sale C) → **6 fallos** (P1 = 3, P2 = 3). Un quantum más grande **mantiene la localidad** de cada proceso. Es uno de los costos ocultos de cambiar de proceso muy seguido.

</Solucion>
</Practica>

## Ejercicio 3: prioridad + LRU, comparado con FCFS

Todos llegan en t = 0. Prioridad **no expropiativa**, **número mayor = más prioridad**. 3 frames y LRU.

| Proceso | Prioridad | Referencias |
| :-: | :-: | --- |
| P1 | 2 | A, B, A |
| P2 | 3 | C, D, C |
| P3 | 1 | E, A, E |

<Practica nivel={3} titulo="Solo: orden, cadena global, fallos y páginas finales, con prioridad y con FCFS">

<Solucion titulo="Comparar: con prioridad (5 fallos)">

Orden: **P2 (3) → P1 (2) → P3 (1)**. Cadena: `C D C · A B A · E A E`.

| Ref. | C | D | C | A | B | A | E | A | E |
| --- | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| Proc. | P2 | P2 | P2 | P1 | P1 | P1 | P3 | P3 | P3 |
| f0 | C | C | C | C | C | C | **E** | E | E |
| f1 | | D | D | D | **B** | B | B | B | B |
| f2 | | | | A | A | A | A | A | A |
| Fallo | ✗ | ✗ | | ✗ | ✗ | | ✗ | | |
| Sale | | | | | D | | C | | |

**5 fallos** (P2 = 2, P1 = 2, P3 = 1). Quedan **E, B, A**. Cuando entra B, el LRU es **D** (usada en la 2.ª referencia), no C (usada en la 3.ª). Cuando entra E, el LRU es C. P3 tiene **un solo fallo** porque encuentra A ya cargada por P1.

</Solucion>

<Solucion titulo="Comparar: con FCFS P1, P2, P3 (6 fallos)">

Cadena: `A B A · C D C · E A E`.

| Ref. | A | B | A | C | D | C | E | A | E |
| --- | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| f0 | A | A | A | A | A | A | **E** | E | E |
| f1 | | B | B | B | **D** | D | D | **A** | A |
| f2 | | | | C | C | C | C | C | C |
| Fallo | ✗ | ✗ | | ✗ | ✗ | | ✗ | ✗ | |
| Sale | | | | | B | | A | D | |

**6 fallos** (2 por proceso). Quedan **E, A, C**.

**Comparación:** con prioridad, P1 (que usa A) corre **justo antes** de P3 (que también usa A), así que A sigue cargada. Con FCFS, entre P1 y P3 corre P2, que llena la memoria con C y D y hace que A sea expulsada: P3 falla en A. **El orden de ejecución cambia la localidad de la cadena global.**

</Solucion>
</Practica>
