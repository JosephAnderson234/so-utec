<EnSimple>
Un scheduler en C es **un bucle con tres preguntas**: ¿queda alguien sin terminar?, ¿quién de los listos gana?, ¿cuánto lo dejo correr? Todas las políticas comparten el bucle y solo cambian **la función que elige** (llegada, ráfaga, prioridad, turno) y **cuánto corre** (todo, un quantum, hasta la próxima llegada). Si memorizas el esqueleto, en el examen solo escribes la parte que cambia.

## El esqueleto común

```c
while (quedan procesos sin terminar) {
    elegido = el mejor de los LISTOS (llegada <= current_time y remaining > 0);
    if (no hay ninguno) {
        IDLE desde current_time hasta la próxima llegada;
        continue;
    }
    run(elegido, cuánto: todo | min(QUANTUM, remaining) | hasta la próxima llegada);
    si terminó: anotar completion;
    si no (RR): admitir a los que llegaron y DESPUÉS reinsertarlo al final;
}
```

| Política | ¿Quién gana? | ¿Cuánto corre? |
| --- | --- | --- |
| FCFS | menor `arrival` | todo |
| SJF | menor `burst` (empate: menor `arrival`) | todo |
| Prioridad no expropiativa | mayor `priority` (empate: menor `arrival`) | todo |
| RR | el primero de la cola | `min(QUANTUM, remaining)` |
| SRTF | menor `remaining` | hasta terminar **o** hasta la próxima llegada |
| Prioridad + RR | mayor `priority`; dentro del mismo nivel, turno | si está solo en su nivel, todo; si no, `min(QUANTUM, remaining)` |

<Detective titulo="el RR que nunca termina" sintoma="Usas el <code>run()</code> de <code>base-scheduler.c</code> y escribes <code>run(&amp;tasks[i], QUANTUM);</code> en un bucle de RR. El programa imprime algunos turnos y después <strong>se queda colgado</strong> sin imprimir nada más." pista="Lee la primera línea de <code>run()</code> en la plantilla. ¿Qué pasa cuando a un proceso le quedan 1 o 2 unidades y le pides correr 3?">

La plantilla empieza con:

```c
if (slice <= 0 || slice > task->remaining)
    return;
```

Si a P1 le queda 1 y llamas `run(&tasks[i], 3)`, `run` **regresa sin hacer nada**: `remaining` sigue en 1, `current_time` no avanza y tu bucle vuelve a elegir a P1 para siempre. **Corrección:** calcula el trozo antes de llamar:

```c
int slice = tasks[i].remaining < QUANTUM ? tasks[i].remaining : QUANTUM;
run(&tasks[i], slice);
```

Es también lo que pide la hoja: «si termina antes del quantum, la CPU podrá atender al siguiente sin consumir el tiempo sobrante».

</Detective>

## Ejercicios 1–4, 8 y 9: los no expropiativos con métricas

Un solo archivo resuelve FCFS con CPU inactiva (ej. 1–2), SJF (ej. 3), prioridad (ej. 4), las métricas (ej. 8) y la comparación con los datos reiniciados (ej. 9). La política se cambia pasando **una función de comparación** distinta.

<Practica nivel={2} titulo="Complétalo antes de mirar: la función que elige">

Escribe `pick()`: debe devolver el índice del mejor proceso **listo** según `better`, o `-1` si no hay ninguno listo. Ten en cuenta dos condiciones: que ya haya llegado y que no haya terminado.

<Solucion titulo="Comparar">

```c
int pick(int (*better)(Task *, Task *)) {
    int best = -1;
    for (int i = 0; i < N; i++) {
        if (tasks[i].remaining == 0 || tasks[i].arrival > current_time)
            continue;
        if (best == -1 || better(&tasks[i], &tasks[best]))
            best = i;
    }
    return best;
}
```

Como `better` usa comparaciones **estrictas** y recorre en orden, ante un empate total gana el de menor índice.

</Solucion>
</Practica>

```c
#include <stdio.h>
#include <string.h>

#define N 5

typedef struct {
    char name[20];
    int priority;
    int arrival;
    int burst;
    int remaining;
    int completion;
} Task;

Task base[N] = {
    {"P1", 3, 0, 7, 7, 0},
    {"P2", 1, 2, 3, 3, 0},
    {"P3", 4, 4, 2, 2, 0},
    {"P4", 2, 5, 4, 4, 0},
    {"P5", 5, 8, 5, 5, 0}
};

Task tasks[N];
int current_time = 0;

void reset(void) {
    memcpy(tasks, base, sizeof(tasks));
    for (int i = 0; i < N; i++) {
        tasks[i].remaining = tasks[i].burst;
        tasks[i].completion = -1;
    }
    current_time = 0;
}

void run(Task *task, int slice) {
    if (slice <= 0 || slice > task->remaining)
        return;
    printf("t=%d -> t=%d | %s (%d units)\n",
           current_time, current_time + slice, task->name, slice);
    task->remaining -= slice;
    current_time += slice;
    if (task->remaining == 0)
        task->completion = current_time;
}

int better_fcfs(Task *a, Task *b) {
    return a->arrival < b->arrival;
}

int better_sjf(Task *a, Task *b) {
    if (a->burst != b->burst)
        return a->burst < b->burst;
    return a->arrival < b->arrival;
}

int better_priority(Task *a, Task *b) {
    if (a->priority != b->priority)
        return a->priority > b->priority;
    return a->arrival < b->arrival;
}

int pick(int (*better)(Task *, Task *)) {
    int best = -1;
    for (int i = 0; i < N; i++) {
        if (tasks[i].remaining == 0 || tasks[i].arrival > current_time)
            continue;
        if (best == -1 || better(&tasks[i], &tasks[best]))
            best = i;
    }
    return best;
}

int next_arrival(void) {
    int t = -1;
    for (int i = 0; i < N; i++)
        if (tasks[i].remaining > 0 && (t == -1 || tasks[i].arrival < t))
            t = tasks[i].arrival;
    return t;
}

void schedule(int (*better)(Task *, Task *)) {
    int done = 0;
    while (done < N) {
        int i = pick(better);
        if (i == -1) {
            int t = next_arrival();
            printf("t=%d -> t=%d | IDLE\n", current_time, t);
            current_time = t;
            continue;
        }
        run(&tasks[i], tasks[i].remaining);
        done++;
    }
}

double report(void) {
    double tat_sum = 0, wt_sum = 0;
    printf("%-4s %4s %4s %4s %4s %4s\n", "Proc", "Arr", "Bur", "Fin", "TAT", "WT");
    for (int i = 0; i < N; i++) {
        int tat = tasks[i].completion - tasks[i].arrival;
        int wt = tat - tasks[i].burst;
        tat_sum += tat;
        wt_sum += wt;
        printf("%-4s %4d %4d %4d %4d %4d\n", tasks[i].name, tasks[i].arrival,
               tasks[i].burst, tasks[i].completion, tat, wt);
    }
    printf("Promedio TAT = %.2f | Promedio WT = %.2f\n", tat_sum / N, wt_sum / N);
    return wt_sum / N;
}

int main(void) {
    reset();
    printf("== FCFS\n");
    schedule(better_fcfs);
    double w_fcfs = report();

    reset();
    printf("\n== SJF no preemptive\n");
    schedule(better_sjf);
    double w_sjf = report();

    reset();
    printf("\n== Priority no preemptive (mayor numero = mayor prioridad)\n");
    schedule(better_priority);
    report();

    printf("\nWT promedio: FCFS = %.2f, SJF = %.2f -> menor: %s\n",
           w_fcfs, w_sjf, w_sjf < w_fcfs ? "SJF" : (w_fcfs < w_sjf ? "FCFS" : "empate"));
    return 0;
}
```

## Ejercicios 5, 6 y 10: Round Robin

La cola es un arreglo circular de índices. El orden importa: **primero se admite a los que llegaron durante el turno y después se reinserta al que corrió** (hoja, ej. 6). El arreglo debe estar ordenado por `arrival`, como en la plantilla.

<Practica nivel={3} titulo="Solo: escribe schedule() de RR con llegadas">

Tienes `push(i)`, `pop()`, `empty()` y una variable `next` que apunta al siguiente proceso que aún no entra a la cola. Escribe `admit()` y `schedule()`, incluido el caso en que la cola queda vacía.

<Solucion titulo="Comparar: rr.c completo">

```c
#include <stdio.h>

#define N 5
#define QUANTUM 3

typedef struct {
    char name[20];
    int priority;
    int arrival;
    int burst;
    int remaining;
} Task;

Task tasks[N] = {
    {"P1", 3, 0, 7, 7},
    {"P2", 1, 2, 3, 3},
    {"P3", 4, 4, 2, 2},
    {"P4", 2, 5, 4, 4},
    {"P5", 5, 8, 5, 5}
};

int current_time = 0;

int queue[64];
int head = 0, tail = 0;

void push(int i) { queue[tail++ % 64] = i; }
int pop(void) { return queue[head++ % 64]; }
int empty(void) { return head == tail; }

void run(Task *task, int slice) {
    if (slice <= 0 || slice > task->remaining)
        return;
    printf("t=%d -> t=%d | %s (%d units)", current_time, current_time + slice,
           task->name, slice);
    task->remaining -= slice;
    current_time += slice;
    printf(" | restante %s = %d\n", task->name, task->remaining);
}

int next = 0;

void admit(void) {
    while (next < N && tasks[next].arrival <= current_time)
        push(next++);
}

void schedule(void) {
    int done = 0;
    admit();
    while (done < N) {
        if (empty()) {
            printf("t=%d -> t=%d | IDLE\n", current_time, tasks[next].arrival);
            current_time = tasks[next].arrival;
            admit();
            continue;
        }
        int i = pop();
        int slice = tasks[i].remaining < QUANTUM ? tasks[i].remaining : QUANTUM;
        run(&tasks[i], slice);
        admit();
        if (tasks[i].remaining > 0)
            push(i);
        else
            done++;
    }
}

int main(void) {
    schedule();
    return 0;
}
```

<Solucion titulo="Extra: SRTF (srtf.c), por si piden la versión expropiativa de SJF">

La idea: el elegido corre hasta que **termina o llega alguien**, lo que pase primero, y ahí se vuelve a elegir.

```c
#include <stdio.h>

#define N 5

typedef struct {
    char name[20];
    int priority;
    int arrival;
    int burst;
    int remaining;
} Task;

Task tasks[N] = {
    {"P1", 3, 0, 7, 7},
    {"P2", 1, 2, 3, 3},
    {"P3", 4, 4, 2, 2},
    {"P4", 2, 5, 4, 4},
    {"P5", 5, 8, 5, 5}
};

int current_time = 0;

int pick(void) {
    int best = -1;
    for (int i = 0; i < N; i++) {
        if (tasks[i].remaining == 0 || tasks[i].arrival > current_time)
            continue;
        if (best == -1 || tasks[i].remaining < tasks[best].remaining ||
            (tasks[i].remaining == tasks[best].remaining &&
             tasks[i].arrival < tasks[best].arrival))
            best = i;
    }
    return best;
}

int next_event(int running) {
    int end = current_time + tasks[running].remaining;
    for (int i = 0; i < N; i++)
        if (tasks[i].remaining > 0 && tasks[i].arrival > current_time && tasks[i].arrival < end)
            end = tasks[i].arrival;
    return end;
}

void schedule(void) {
    int done = 0, last = -1, start = 0;
    while (done < N) {
        int i = pick();
        if (i == -1) {
            int t = -1;
            for (int k = 0; k < N; k++)
                if (tasks[k].remaining > 0 && (t == -1 || tasks[k].arrival < t))
                    t = tasks[k].arrival;
            printf("t=%d -> t=%d | IDLE\n", current_time, t);
            current_time = t;
            continue;
        }
        if (i != last) {
            if (last != -1 && start < current_time)
                printf("t=%d -> t=%d | %s\n", start, current_time, tasks[last].name);
            start = current_time;
            last = i;
        }
        int until = next_event(i);
        tasks[i].remaining -= until - current_time;
        current_time = until;
        if (tasks[i].remaining == 0) {
            printf("t=%d -> t=%d | %s (termina)\n", start, current_time, tasks[i].name);
            done++;
            last = -1;
        }
    }
}

int main(void) {
    schedule();
    return 0;
}
```

```text
t=0 -> t=2 | P1
t=2 -> t=5 | P2 (termina)
t=5 -> t=7 | P3 (termina)
t=7 -> t=11 | P4 (termina)
t=11 -> t=16 | P1 (termina)
t=16 -> t=21 | P5 (termina)
```

En t = 11, P1 y P5 tienen restante 5: gana P1 porque llegó antes.

## El framework: completar los `TODO`

Así está cada `schedule_<política>.c` al descargarlo:

```c
struct node *head = NULL;

void add (char *name, int priority, int burst) {
	// TODO
}

Task *pick_next_task (struct node *head) {
	// TODO
}

void schedule () {
	// TODO
}
```

Lo que tienes que saber de la lista (`list.c`):

- `head` apunta a un **nodo cabecera vacío**; el primer `Task` es `head->next->task`. La lista está vacía cuando `head->next == NULL`.
- `insert(&head, t)` agrega **al final**, así que la lista queda en el orden del archivo (FCFS).
- `delete(&head, t)` busca por **nombre** con `strcmp` y desengancha el nodo (no libera el `Task`).
- `run(t, slice)` solo **imprime** `Running task = [nombre] [prioridad] [burst] for slice units.`: no cambia `burst`; si haces RR, lo descuentas tú.

<Practica nivel={1} titulo="Resuelto: SJF y prioridad en el framework">

`add` es igual en las cuatro políticas: crea el `Task` y lo inserta. La diferencia está en `pick_next_task`.

```c
#include <stdlib.h>

#include "list.h"
#include "schedulers.h"
#include "task.h"
#include "cpu.h"

struct node *head = NULL;
int nextTid = 0;

void add (char *name, int priority, int burst) {
	Task *t = malloc(sizeof(Task));
	t->tid = nextTid++;
	t->name = name;
	t->priority = priority;
	t->burst = burst;
	insert(&head, t);
}

Task *pick_next_task (struct node *head) {
	Task *best = head->next->task;
	for (struct node *n = head->next->next; n != NULL; n = n->next)
		if (n->task->burst < best->burst)
			best = n->task;
	return best;
}

void schedule () {
	if (head == NULL)
		return;
	while (head->next != NULL) {
		Task *t = pick_next_task(head);
		run(t, t->burst);
		delete(&head, t);
	}
}
```

Para **prioridad**, el archivo es idéntico salvo una línea de `pick_next_task`:

```c
		if (n->task->priority > best->priority)
```

La comparación es **estricta** (`<` y `>`): ante un empate se queda el que estaba antes en la lista, es decir, el primero del archivo. Con `<=` invertirías los desempates.

</Practica>

<Practica nivel={3} titulo="Solo: RR en el framework">

Pista: en RR, `pick_next_task` es simplemente el primero de la lista. Para «mandar al final» al que no terminó, combina `delete` e `insert`.

<Solucion titulo="Comparar: schedule_rr.c">

```c
Task *pick_next_task (struct node *head) {
	return head->next->task;
}

void schedule () {
	if (head == NULL)
		return;
	while (head->next != NULL) {
		Task *t = pick_next_task(head);
		int slice = t->burst < QUANTUM ? t->burst : QUANTUM;
		run(t, slice);
		t->burst -= slice;
		delete(&head, t);
		if (t->burst > 0)
			insert(&head, t);
	}
}
```

(`add` es el mismo de arriba.) Ojo con el orden: `run` imprime `t->burst` **antes** de descontarlo, así que la salida muestra lo que le quedaba al **empezar** el turno.

</Solucion>
</Practica>

<Practica nivel={4} titulo="Variante: prioridad con RR (priority_rr)">

Regla: se atiende el nivel de mayor prioridad; si en ese nivel hay **un solo** proceso, corre hasta terminar; si hay varios, se turnan con RR.

<Solucion titulo="Comparar: schedule_priority_rr.c">

```c
Task *pick_next_task (struct node *head) {
	Task *best = head->next->task;
	for (struct node *n = head->next->next; n != NULL; n = n->next)
		if (n->task->priority > best->priority)
			best = n->task;
	return best;
}

int same_priority (int p) {
	int count = 0;
	for (struct node *n = head->next; n != NULL; n = n->next)
		if (n->task->priority == p)
			count++;
	return count;
}

void schedule () {
	if (head == NULL)
		return;
	while (head->next != NULL) {
		Task *t = pick_next_task(head);
		if (same_priority(t->priority) == 1) {
			run(t, t->burst);
			delete(&head, t);
			continue;
		}
		int slice = t->burst < QUANTUM ? t->burst : QUANTUM;
		run(t, slice);
		t->burst -= slice;
		delete(&head, t);
		if (t->burst > 0)
			insert(&head, t);
	}
}
```

¿Por qué funciona el turno? Al reinsertar `t` **al final**, el próximo `pick_next_task` encuentra primero a otro proceso del mismo nivel.

</Solucion>

En el framework todos llegan en t = 0, así que turnaround = fin, waiting = fin − ráfaga original y response = primer inicio. El problema: `run` no lleva el tiempo y en RR `burst` se va descontando. ¿Qué guardas?

<Solucion titulo="Comparar (salida verificada contra un script independiente)">

Guarda por `tid` la ráfaga **original**, el primer inicio y el fin, y lleva tu propio reloj `now`:

```c
#define MAXT 100

int now = 0;
int original[MAXT], first[MAXT], finish[MAXT];

void add (char *name, int priority, int burst) {
	Task *t = malloc(sizeof(Task));
	t->tid = nextTid++;
	t->name = name;
	t->priority = priority;
	t->burst = burst;
	original[t->tid] = burst;
	first[t->tid] = -1;
	insert(&head, t);
}

void schedule () {
	if (head == NULL)
		return;
	while (head->next != NULL) {
		Task *t = pick_next_task(head);
		int slice = t->burst < QUANTUM ? t->burst : QUANTUM;
		if (first[t->tid] == -1)
			first[t->tid] = now;
		run(t, slice);
		now += slice;
		t->burst -= slice;
		delete(&head, t);
		if (t->burst > 0)
			insert(&head, t);
		else
			finish[t->tid] = now;
	}
	double tat = 0, wt = 0, rt = 0;
	for (int i = 0; i < nextTid; i++) {
		tat += finish[i];
		wt += finish[i] - original[i];
		rt += first[i];
	}
	printf("Promedio turnaround = %.2f\n", tat / nextTid);
	printf("Promedio waiting    = %.2f\n", wt / nextTid);
	printf("Promedio response   = %.2f\n", rt / nextTid);
}
```

<Detective titulo="lo que está mal en el propio framework" sintoma="El <code>driver.c</code> oficial compila y funciona con <code>schedule.txt</code>, pero si le pasas un archivo que no existe, el programa <strong>se cae con segmentation fault</strong> en vez de imprimir «open file». Y Valgrind, con <code>schedule.txt</code>, reporta 25 bloques sin liberar al terminar." pista="¿Qué devuelve <code>fopen</code> cuando falla? ¿Cuánto vale <code>temp</code> después del tercer <code>strsep</code>?">

1. `if (in < 0)` compara un **puntero** con 0 usando `<`. `fopen` devuelve **`NULL`** al fallar, y `NULL < 0` es falso: el error no se detecta y `fgets(task, SIZE, NULL)` revienta. Lo correcto es `if (in == NULL)`.
2. `strsep` va avanzando `temp`, y después del último campo lo deja en `NULL`. Entonces `free(temp)` es `free(NULL)`, que no hace nada, y el bloque de `strdup` **nunca se libera**. Pero tampoco se puede liberar ahí, porque `name` apunta dentro de ese bloque y el `Task` lo sigue usando. La forma correcta es guardar el puntero original (`char *line = strdup(task); temp = line;`) y liberarlo al final del programa.
3. El nodo cabecera se crea con `malloc` en el primer `insert` y nunca se libera, y `delete` desengancha nodos sin hacerles `free`.

No es lo que te van a pedir, pero si en el examen aparece «encuentre el error en este código», estos son los candidatos clásicos. En C, **comparar un puntero con `< 0` es casi siempre un bug**.
